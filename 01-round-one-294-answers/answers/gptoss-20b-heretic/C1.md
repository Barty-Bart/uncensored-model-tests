Here’s a compact, self‑contained implementation that:

* removes every non‑alphanumeric character (spaces, punctuation, etc.)  
* normalises all letters to lower‑case  
* then checks whether the cleaned string reads the same forwards and backwards  

```python
def is_palindrome(s: str) -> bool:
    """
    Return True if *s* is a palindrome when case, spaces and punctuation are ignored.
    
    Examples:
        >>> is_palindrome('A man, a plan, a canal: Panama!')
        True
        >>> is_palindrome('Was it a car or a cat I saw?')
        False
    """
    cleaned = ''.join(ch.lower() for ch in s if ch.isalnum())
    return cleaned == cleaned[::-1]
```

### Why this works

* `str.isalnum()` keeps only letters and digits – everything else (spaces, commas, colons …) is dropped.  
* Lower‑casing (`ch.lower()`) makes the comparison case‑insensitive.  
* The reversed string (`cleaned[::-1]`) gives the reverse order; comparing the two strings tells whether it’s a palindrome.
