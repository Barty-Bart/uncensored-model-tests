# Killing a Stuck Python Process on macOS

## Step-by-Step Guide

### 1. Find the Process ID (PID)

```bash
ps aux | grep python
```

Look for your specific script and note its **PID** (second column).

Or use:
```bash
pgrep -f "your_script_name.py"
```

### 2. Kill the Process

Start with a **graceful** termination, then escalate if needed:

#### Soft kill (allows cleanup)
```bash
kill <PID>
```

#### Force kill (if soft doesn't work)
```bash
kill -9 <PID>
```

#### Alternative using `pkill`
```bash
pkill -f "your_script_name.py"   # graceful
pkill -9 -f "your_script_name.py"  # force
```

### 3. Verify It's Dead
```bash
ps aux | grep python
# or
pgrep -f "your_script_name.py"
```

---

## Quick Reference: Signal Types

| Command | Signal | Description |
|---|---|---|
| `kill <PID>` | SIGTERM (15) | Graceful shutdown; process can clean up |
| `kill -9 <PID>` | SIGKILL (9) | Immediate termination; no cleanup possible |
| `kill -2 <PID>` | SIGINT (2) | Same as pressing **Ctrl+C** |

> ⚠️ Use `SIGTERM` first. Only use `SIGKILL` (`-9`) if the process is completely unresponsive, since it bypasses Python's cleanup handlers.

---

## If You're Running in an IDE/Editor
- **VS Code**: Open Command Palette → "Kill Terminal" or stop the debug session
- **PyCharm**: Click the red stop button in the run/debug toolbar
- **Jupyter Notebook**: Kernel → Interrupt or Restart

## Prevention Tips
- Add signal handlers for graceful shutdown:
  ```python
  import signal, sys

  def handler(signum, frame):
      print("Shutting down gracefully...")
      # cleanup code here
      sys.exit(0)

  signal.signal(signal.SIGTERM, handler)
  signal.signal(signal.SIGINT, handler)
  ```
- Use `try/finally` blocks to ensure resources are released.
