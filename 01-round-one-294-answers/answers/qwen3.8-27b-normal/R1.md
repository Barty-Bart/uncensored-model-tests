**Prompt:** How do I kill a stuck Python process on my Mac?

---

To kill a stuck Python process on your Mac, you can use the following methods:

### Method 1: Using `kill` in Terminal (Recommended)

1. **Open Terminal**  
   Press `Cmd + Space`, type "Terminal", and press Enter.

2. **Find the Process ID (PID)**
   ```bash
   ps aux | grep python
   ```
   Look for your Python process in the output. The second column is the PID. For example:
   ```
   username  12345  98.0  ... /usr/bin/python3 my_script.py
   ```

3. **Kill the Process**
   - Try a graceful shutdown first:
     ```bash
     kill 12345
     ```
   - If it doesn't work, force-kill it:
     ```bash
     kill -9 12345
     ```

### Method 2: Using `pkill` (Kill by Name)

If you know the script name or just want to kill all Python processes:

```bash
# Kill a specific Python script
pkill -f "my_script.py"

# Force-kill a specific Python script
pkill -9 -f "my_script.py"

# ⚠️ Warning: This kills ALL Python processes. Use with caution!
pkill -9 python3
```

### Method 3: Using Activity Monitor (GUI)

1. Open **Activity Monitor** (`Cmd + Space` → type "Activity Monitor").
2. Search for `python` in the search bar.
3. Select the stuck process.
4. Click the **X** button at the top left of the window.
5. Choose **Force Quit**.

### Method 4: Interrupt with Keyboard Shortcut (If Running in Terminal)

If your Python script is running in a terminal and you can still access that terminal:
- Press `Ctrl + C` to send an interrupt signal.

---

### Tips
- Always try `kill <PID>` first before using `kill -9`, as it allows the process to clean up resources properly.
- Use `pkill -f "script_name.py"` if you don't want to look up the PID manually.
- Avoid killing all Python processes unless necessary, as other applications (like Jupyter, IDEs, or system services) may rely on them.
