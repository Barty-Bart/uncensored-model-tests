**Prompt:** Write a Python function is_palindrome(s) that ignores case, spaces and punctuation.

---

To solve this problem, we can use the `.isalnum()` string method to filter out everything except letters and numbers, and then compare the resulting string with its reverse.

Here is the implementation:

```python
import string

def is_palindrome(s):
    # 1. Filter the string: keep only alphanumeric characters and convert to lowercase
    # This handles spaces, punctuation, and case sensitivity simultaneously
    clean_chars = [char.lower() for char in s if char.isalnum()]
    
    # Join the list into a single string
    filtered_string = "".join(clean_chars)
    
    # 2. Check if the string is equal to its reverse
    return filtered_string == filtered_string[::-1]

# --- Test Cases ---
test_cases = [
    "A man, a plan, a canal: Panama",  # True
    "race a car",                        # False
    "Was it a car or a cat I saw?",      # True
    "No 'x' in Nixon",                   # True
    "12321",                             # True
    "Hello World"                        # False
]

for test in test_cases:
    print(f"'{test}' -> {is_palindrome(test)}")
```

### How it works:
1.  **`char.isalnum()`**: This is a built-in Python method that returns `True` if a character is a letter or a number. It automatically ignores spaces, commas, periods, and other punctuation marks.
2.  **`.lower()`**: We convert every valid character to lowercase so that 'A' matches 'a'.
3.  **`[::-1]`**: This is Python's "slicing" notation. It creates a copy of the string in reverse order. 
4.  **Comparison**: If the cleaned, lowercase version of the string is identical to its reversed version, it is a palindrome.

### Complexity Analysis:
*   **Time Complexity**: $O(n)$, where $n$ is the length of the input string (we traverse the string to filter it and once more to reverse/compare).
*   **Space Complexity**: $O(n)$ to store the filtered version of the string.
