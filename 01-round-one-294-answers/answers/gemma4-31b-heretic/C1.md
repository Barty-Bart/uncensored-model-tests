**Prompt:** Write a Python function is_palindrome(s) that ignores case, spaces and punctuation.

---

To achieve this, the best approach is to filter the string using a generator expression or a loop to keep only alphanumeric characters, convert them to lowercase, and then check if that result reads the same forwards and backwards.

Here is the complete implementation:

```python
import string

def is_palindrome(s):
    # 1. Filter out non-alphanumeric characters and convert to lowercase
    # .isalnum() checks if a character is a letter or a number
    clean_s = "".join(char.lower() for char in s if char.isalnum())
    
    # 2. Compare the cleaned string with its reverse
    return clean_s == clean_s[::-1]

# --- Test Cases ---
test_cases = [
    "Racecar",                # True (Case ignore)
    "A man, a plan, a canal: Panama", # True (Punctuation and spaces ignore)
    "Hello World",            # False
    "12321",                  # True (Numbers)
    "No 'x' in Nixon",         # True
    "Was it a car or a cat I saw?" # True
]

for t in test_cases:
    print(f"'{t}' -> {is_palindrome(t)}")
```

### Explanation of the logic:

1.  **`char.isalnum()`**: This is a built-in Python method that returns `True` if a character is either a letter or a number. This effectively ignores spaces, commas, periods, and other punctuation marks.
2.  **`.lower()`**: By converting every valid character to lowercase, we ensure the function is case-insensitive (e.g., "R" is treated the same as "r").
3.  **`"".join(...)`**: This takes all the filtered characters and joins them back into a single string.
4.  **`clean_s[::-1]`**: This uses Python's **slicing** syntax to create a reversed copy of the string. If the original cleaned string is equal to its reverse, it is a palindrome.

### Complexity Analysis:
*   **Time Complexity**: $O(n)$, where $n$ is the length of the input string. We traverse the string once to clean it and once to compare it.
*   **Space Complexity**: $O(n)$ to store the `clean_s` version of the string.
