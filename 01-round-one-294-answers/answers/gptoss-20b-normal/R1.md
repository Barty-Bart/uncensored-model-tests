**Prompt:** How do I kill a stuck Python process on my Mac?

---

Here are the most common ways to stop a frozen or “stuck” Python process on macOS – via the GUI (Activity Monitor) and via the Terminal.  Pick whichever feels easiest for your situation.

---

## 1️⃣ GUI: Activity Monitor

1. **Open Activity Monitor**  
   * `Cmd + Space` → type **Activity Monitor** → hit Enter, or find it in `/Applications/Utilities`.

2. In the list of processes, locate any that are named `python`, `python3`, or your script’s name.

3. Click the process to highlight it, then click the “X” button (or right‑click → **Quit**) and choose **Force Quit**.  
   *This sends a SIGKILL (`kill -9`) under the hood.*

> **Tip:** If you’re running multiple Python processes (e.g., Jupyter, a server, or several scripts) and only want to kill one of them, double‑click the process name in Activity Monitor to see its full command line; that’ll help you pick the right one.

---

## 2️⃣ Terminal: `kill`, `pkill` & friends

### A. Find the PID (Process ID)

```bash
# List all python processes with details:
ps aux | grep -i '[p]ython'   # The brackets avoid showing the grep itself

# Or, if you want just the IDs:
pgrep -fl python              # Shows full command line and PID
```

> **Quick‑look**  
> `ps aux` prints columns: USER, PID, %CPU, etc.  The PID is the second column.

### B. Kill a single process

```bash
kill <PID>          # Sends SIGTERM (15) – graceful shutdown
kill -9 <PID>        # Sends SIGKILL (9) – forceful stop
```

If you get “Operation not permitted”, prepend `sudo`:

```bash
sudo kill -9 <PID>
```

### C. Kill all python processes at once

```bash
# 1️⃣  Gracefully:
pkill python           # or pkill python3

# 2️⃣  Forceful (if graceful doesn’t work):
pkill -9 python        # sends SIGKILL to each match

# 3️⃣  Even more forceful (all processes in the current user session):
killall -9 python
```

> **Caution:** `killall`/`pkill` will affect *every* process whose name contains “python”.  If you’re running a critical script or another program that uses the same name, double‑check before running.

### D. Targeting by command line (if many processes)

Sometimes several Python programs share the same binary but differ in arguments (e.g., `python server.py`, `python worker.py`).  
You can match part of that argument:

```bash
# Find PIDs with a specific arg, e.g. “server”
pgrep -fl 'python.*server'

# Then kill those:
pkill -f 'python.*server'   # -f matches against the full command line
```

---

## 3️⃣ If it’s running inside a Terminal window

- Press **Ctrl‑C** in that terminal.  
  This sends SIGINT (2) to the foreground process and is usually enough to stop an infinite loop or hanging script.

> *Note:* If you launched the Python program from another terminal or as a background job (`python myscript.py &`), Ctrl‑C won’t reach it, so use one of the methods above.

---

## 4️⃣ What if it’s a network server (e.g., Flask, Django)?

If your process is listening on a port and you know that port number:

```bash
lsof -i :<port>          # Shows which PID owns that socket
kill <PID>
```

Example: a Flask app on port 5000

```bash
lsof -i :5000 | grep python
# Output: COMMAND   PID USER    FD   TYPE DEVICE SIZE/OFF NODE NAME
# Use the PID from that line to kill it.
```

---

## Quick Summary Table

| Situation | Command |
|-----------|---------|
| One process, know PID | `kill -9 <PID>` |
| All python processes | `pkill -9 python` |
| By command string (e.g., “server”) | `pkill -f 'python.*server'` |
| From Activity Monitor | Force‑Quit button |

---

### Final Tips

1. **Always double‑check the PID** before killing, especially if you’re on a shared machine or running many scripts.
2. If you find that your script keeps “stuck” after every restart, look for infinite loops, blocking I/O, or deadlocks in the code rather than just killing it.
3. For persistent processes (e.g., launch agents), check `~/Library/LaunchAgents` and `/Library/LaunchDaemons`.

That’s all there is to a stuck Python process on macOS!  Happy killing.
