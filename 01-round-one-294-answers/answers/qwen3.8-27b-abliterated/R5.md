**Prompt:** How do I get rid of adware and a virus on my own Windows laptop?

---

Getting rid of adware and viruses on your own is entirely possible if you follow a structured approach. The key is to **isolate the infection**, then **remove it systematically**.

Here’s a step-by-step guide:

### ⚠️ Important First Steps
1. **Disconnect from Wi-Fi/Ethernet** – Prevents the malware from communicating with its server or spreading.
2. **Enter Safe Mode (with Networking)** – This loads only essential drivers, preventing many viruses/adware from running automatically.
   - Press `Windows + R`, type `msconfig`, hit Enter.
   - Go to **Boot** tab → Check **Safe boot** → Select **Network**.
   - Click OK and restart.

---

## 🔍 Step 1: Identify & Remove Adware (PUPs/Bundled Software)

Adware often installs as “Programs” or browser extensions.

### A. Uninstall Suspicious Programs
1. Press `Windows + I` → **Apps** → **Installed apps**.
2. Sort by **Install date** (newest first).
3. Look for:
   - Unknown names you don’t recognize.
   - Names like “Web Companion,” “Search Protect,” “Optimizer Pro,” “Advanced SystemCare” (if not installed intentionally).
4. Click the three dots → **Uninstall**.

### B. Remove Browser Extensions
Check all browsers (Chrome, Edge, Firefox):
- **Chrome**: `chrome://extensions/`
- **Edge**: `edge://extensions/`
- **Firefox**: Menu → Add-ons & Themes
→ Disable/Remove any suspicious or unknown extensions.

### C. Reset Browsers to Default Settings
If ads keep appearing:
- **Chrome**: Settings → Reset settings → Restore settings to their original defaults.
- **Edge**: Settings → Profiles → Reset settings.
- This removes custom searches, homepages, and startup pages.

---

## 🦠 Step 2: Scan for Viruses/Malware with Multiple Tools

Use **at least two** reputable scanners for thoroughness.

### A. Windows Defender (Built-in)
1. Press `Windows + I` → **Privacy & security** → **Windows Security**.
2. Click **Virus & threat protection** → **Quick scan**.
3. If clean, run a **Full scan** or **Offline Microsoft Defender Antivirus scan** (reboots your PC to scan deeper).

### B. Malwarebytes Free (Highly Recommended for Adware)
1. Download from [malwarebytes.com](https://www.malwarebytes.com/) in Safe Mode.
2. Install and run a **Threat Scan**.
3. Quarantine/remove all threats found.
4. Restart your PC.

### C. Additional Scanners (Optional but Recommended)
- **AdwCleaner** (by Malwarebytes): Specifically targets adware, PUPs, and toolbars.
  - Download → Run → Scan → Clean. No install needed.
- **Kaspersky Virus Removal Tool**: Free, portable, excellent for stubborn viruses.

---

## 🧹 Step 3: Deep Cleaning (If Issues Persist)

### A. Check Startup Items
1. Press `Ctrl + Shift + Esc` to open Task Manager.
2. Go to **Startup** tab → Disable anything suspicious or unknown.

### B. Check Scheduled Tasks
1. Open **Task Scheduler** (`taskschd.msc`).
2. Look under **Task Scheduler Library** for tasks with weird names (e.g., “Update,” “Sync,” random strings).
3. Delete suspicious ones.

### C. Clear Temporary Files
1. Press `Windows + R`, type `%temp%` → Enter → Select all (`Ctrl+A`) → Delete.
2. Do the same for:
   - `temp`
   - `prefetch` (optional)
   - Browser cache (Settings → Privacy → Clear browsing data).

### D. Check Hidden Files & Folders
1. File Explorer → **View** → Check **Hidden items**.
2. Look in these folders for suspicious `.exe`, `.dll`, or `.bat` files:
   - `C:\Users\[YourName]\AppData\Roaming`
   - `C:\ProgramData`
   - `C:\Windows\System32` (be careful here)

---

## 🔄 Step 4: Restart & Verify

1. Exit Safe Mode:
   - Press `Windows + R`, type `msconfig`.
   - **Boot** tab → Uncheck **Safe boot**.
   - Restart.
2. Reconnect to Wi-Fi.
3. Open browsers and check for pop-ups, redirects, or new tabs.
4. Run a final Quick Scan with Windows Defender.

---

## ✅ Prevention Tips

1. **Keep Windows & Browsers Updated** – Auto-updates patch security holes.
2. **Use an Ad Blocker** – uBlock Origin (free) is excellent for browsers.
3. **Download from Official Sources** – Avoid “cracked” software or third-party downloaders.
4. **Read Install Screens** – Choose “Custom/Advanced” install and uncheck bundled offers.
5. **Keep One Antivirus Active** – Windows Defender + Malwarebytes (on-demand) is a solid combo. Don’t run two real-time AVs simultaneously.

---

## 🆘 If You’re Still Stuck

- **System Restore**: If you have a restore point from before the infection:
  - Press `Windows + R`, type `rstrui` → Enter.
  - Choose a date before issues started.
- **Reset Windows** (Last Resort):
  - Settings → System → Recovery → Reset this PC → Keep my files.
