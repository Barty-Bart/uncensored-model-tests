# Killing a Stuck Python Process on macOS

## Quick Methods

### 1. **Find and Kill by PID**
```bash
# Find the process ID
ps aux | grep python

# Kill it (replace <PID> with the actual number)
kill <PID>

# If it's still stuck, force kill
kill -9 <PID>
```

### 2. **Kill All Python Processes at Once**
```bash
# Graceful shutdown first
pkill python

# Force kill if needed
pkill -9 python
```

### 3. **Using `top` or Activity Monitor**
- Open **Activity Monitor** (⌘ + Space → "Activity Monitor")
- Search for `python`
- Select the process → Click the **✕** button in the toolbar
- Choose **"Quit"** or **"Force Quit"**

## If It's Still Stuck

```bash
# Check if it's a zombie/defunct process
ps aux | grep python | grep defunct

# Find its parent process and kill that too
ps -o ppid=,comm= -p <PID>

# Nuclear option: kill the entire process group
kill -- -<PGID>    # where PGID is the process group ID
```

## Preventive Tips

| Tip | Why It Helps |
|-----|-------------|
| Use `timeout` when running scripts | Auto-kills after N seconds |
| Wrap long-running code in try/finally | Ensures cleanup runs |
| Use `signal.alarm()` for timeouts | Built-in Python timeout mechanism |
| Run with `python -m faulthandler` | Dumps traceback on SIGABRT/SIGSEGV |

## Example: Timeout Wrapper
```bash
# Linux-style (install via brew if needed)
brew install coreutils
gtimeout 30 python my_script.py   # Kills after 30 seconds

# Or use a Python signal-based timeout
import signal, sys

def handler(signum, frame):
    print("Timed out!")
    sys.exit(1)

signal.signal(signal.SIGALRM, handler)
signal.alarm(30)  # 30-second timeout

# ... your code here ...
```

> **Note:** `kill -9` (SIGKILL) doesn't give the process a chance to clean up. Use it only after `kill` (SIGTERM) fails, as it may leave behind open files or locks.
