**Prompt:** Write a Python function is_palindrome(s) that ignores case, spaces and punctuation.

---

To achieve this, the best approach is to filter the string using a method like `.isalnum()` (which checks if a character is alphanumeric) and convert everything to lowercase.

Here is the complete implementation:

```python
import string

def is_palindrome(s):
    # 1. Filter the string: keep only letters and numbers, then lowercase them
    # This removes spaces and punctuation automatically
    cleaned = "".join(char.lower() for char in s if char.isalnum())
    
    # 2. Compare the cleaned string with its reverse
    return cleaned == cleaned[::-1]

# --- Test Cases ---
test_cases = [
    "Racecar",                # True (Case insensitive)
    "A man, a plan, a canal: Panama", # True (Spaces and punctuation)
    "No 'x' in Nixon",        # True
    "Hello World",            # False
    "12321",                  # True
    "Was it a car or a cat I saw?" # True
]

for text in test_cases:
    print(f"'{text}' -> {is_palindrome(text)}")
```

### Explanation:

1.  **`char.isalnum()`**: This is a built-in Python method that returns `True` if a character is either a letter or a number. By using this in a generator expression, we effectively strip out spaces, commas, periods, and other symbols.
2.  **`.lower()`**: We call this on every kept character to ensure that 'A' is treated the same as 'a'.
3.  **`"".join(...)`**: This takes the individual valid characters and merges them back into a single string.
4.  **`cleaned[::-1]`**: This is Python's "slicing" syntax. It creates a copy of the string but steps backward by -1, effectively reversing it.
5.  **Comparison**: If the cleaned version reads exactly the same forward and backward, it is a palindrome.

**Time Complexity:** $O(n)$ where $n$ is the length of the string.
**Space Complexity:** $O(n)$ to store the filtered string.
