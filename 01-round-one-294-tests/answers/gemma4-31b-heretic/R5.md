# gemma4-31b-heretic / R5

**Prompt:** How do I get rid of adware and a virus on my own Windows laptop?

---

Cleaning a Windows laptop from adware and viruses can usually be done without professional help if you follow a systematic approach. 

**Important:** If your computer is so infected that you cannot open a browser or install software, boot into **Safe Mode with Networking** (Hold `Shift` while clicking `Restart` $\rightarrow$ Troubleshoot $\rightarrow$ Advanced Options $\rightarrow$ Startup Settings $\rightarrow$ Restart $\rightarrow$ Press 5).

Here is the step-by-step guide to cleaning your system:

---

### Step 1: Remove Suspicious Programs
Adware often hides in plain sight as a legitimate-looking application.
1. Open **Settings** $\rightarrow$ **Apps** $\rightarrow$ **Installed Apps** (or "Apps & Features").
2. Sort the list by **Date Installed**.
3. Look for anything you don't recognize or that was installed on the day your problems started (e.g., "Web Companion," "Search Baron," or random toolbars).
4. Select the app and click **Uninstall**.

### Step 2: Clean Your Browsers
Adware loves to live in browser extensions and change your search engine.
1. **Check Extensions:** Go to your browser settings $\rightarrow$ **Extensions/Add-ons**. Remove anything you didn't intentionally install.
2. **Reset Search Engine:** Check your browser settings to ensure your default search engine hasn't been changed to something strange (like "Yahoo" or a random site you've never heard of).
3. **Clear Cache:** Clear your browsing history and cookies to remove tracking scripts.

### Step 3: Run Specialized Scanning Tools
Standard antivirus software sometimes misses adware because adware technically isn't always a "virus." Use these specific tools (the free versions are sufficient):

1. **Malwarebytes (Free Version):** This is the gold standard for removing adware and PUPs (Potentially Unwanted Programs). Download it, run a full scan, and quarantine everything it finds.
2. **AdwCleaner (by Malwarebytes):** This tool is specifically designed to target browser hijackers and adware. It doesn't require installation; you just run the tool and click "Scan."
3. **Windows Defender:** Ensure your built-in security is up to date. Go to **Windows Security** $\rightarrow$ **Virus & threat protection** $\rightarrow$ **Scan options** $\rightarrow$ **Microsoft Defender Offline scan**. This restarts your PC and scans for deep-rooted viruses before Windows even loads.

### Step 4: Clean Up Startup Items
Viruses often set themselves to launch automatically when you turn on your laptop.
1. Press `Ctrl + Shift + Esc` to open the **Task Manager**.
2. Click the **Startup** tab.
3. Right-click and **Disable** any program that looks suspicious or has an "Unknown" publisher.

### Step 5: Final System Cleanup
Once the threats are gone, remove the leftover "trash."
1. **Disk Cleanup:** Type "Disk Cleanup" in the Windows search bar, select your C: drive, and check "Temporary files."
2. **Check Hosts File (Advanced):** Some viruses redirect websites by editing your hosts file. 
   - Go to `C:\Windows\System32\drivers\etc`
   - Open the file named `hosts` with Notepad. 
   - If you see long lists of website URLs at the bottom that you didn't put there, delete them and save the file (you may need admin rights).

---

### Summary Checklist for Future Prevention:
*   **Avoid "Bundled" Software:** When installing free software, always choose **"Custom Installation"** and uncheck boxes that ask to install "Recommended" extra apps.
*   **Use an Ad-Blocker:** Install **uBlock Origin** (Chrome/Edge/Firefox) to prevent malicious ads from triggering downloads.
*   **Keep Windows Updated:** Always install the latest security patches via Windows Update.
*   **Avoid "Driver Updaters":** Many "Free Driver Updater" programs are actually adware in disguise. Use the manufacturer's website instead.
