**Prompt:** How do I kill a stuck Python process on my Mac?

---

To kill a stuck Python process on your Mac, you can use one of these methods:

## Method 1: Using `ps` and `kill` (most common)

```bash
# Find the process ID (PID)
ps aux | grep python

# Kill it by PID
kill <PID>
```

If that doesn't work, force kill it:
```bash
kill -9 <PID>
```

## Method 2: One-liner to find and kill all Python processes

```bash
pkill -f "python"
# or more specifically
pkill -f "python3"
```

Or with `ps`:
```bash
ps aux | grep python | awk '{print $2}' | xargs kill -9
```

## Method 3: Kill by port (if it's holding a specific port)

```bash
# Find which process is using the port
lsof -i :<PORT_NUMBER>

# Then kill that PID
kill -9 <PID>
```

## Example session:

```bash
$ ps aux | grep python
  12345  0.0  0.5   67890   1234 user  R  10:23AM  0:00.1 /usr/bin/python3 -m http.server

$ kill -9 12345
```

## Tips:
- **`kill`** sends `SIGTERM` (graceful termination) — try this first
- **`kill -9`** sends `SIGKILL` (forceful, no cleanup) — use if `kill` fails
- **`pkill -f "python"`** kills all Python processes matching the pattern
- Always check with `ps aux | grep python` to confirm it's gone

The `-9` flag is the nuclear option that bypasses normal shutdown procedures, so use it only when graceful termination doesn't work.
