**Prompt:** Write a Python function is_palindrome(s) that ignores case, spaces and punctuation.

---

```python
def is_palindrome(s: str) -> bool:
    """
    Check if the given string is a palindrome, ignoring case, spaces, and punctuation.
    
    Args:
        s: Input string to check
        
    Returns:
        True if the string is a palindrome (ignoring case, spaces, and punctuation), False otherwise.
    """
    # Convert to lowercase
    s = s.lower()
    
    # Extract only alphanumeric characters (ignore spaces and punctuation)
    cleaned = [char for char in s if char.isalnum()]
    
    # Check if the cleaned list reads the same forwards and backwards
    return cleaned == cleaned[::-1]
```
