# Killing a Stuck Python Process on macOS

## Quick Methods (from easiest to most thorough)

### 1. Using `pkill` (Simplest)
```bash
pkill -f python
```
This kills **all** processes whose command line contains "python".

### 2. Using `ps` and `kill` (More Control)
```bash
# Find the Python process ID(s)
ps aux | grep python

# Kill a specific process by PID
kill <PID>

# Force kill if it doesn't respond
kill -9 <PID>
```

### 3. Using `lsof` to Find Processes on Specific Ports
If your stuck Python process is holding a port (e.g., web server):
```bash
lsof -i :<PORT>   # e.g., lsof -i :8080
kill <PID>
```

### 4. Interactive Approach with `htop` or `top`
```bash
# Launch htop if installed (install via Homebrew: brew install htop)
htop

# Or use built-in top, press 'k' to enter PID, then Enter
top -l 1 | grep python
kill <PID>
```

## If You Know It's a Specific Script
```bash
# Find the exact process running your script
ps aux | grep my_script.py

# Kill it gracefully (allows cleanup)
kill <PID>

# Or force kill immediately
kill -9 <PID>
```

## Tips & Best Practices

| Signal | Command | Use Case |
|--------|---------|----------|
| `SIGTERM` (15) | `kill PID` | Graceful shutdown (default) |
| `SIGKILL` (9) | `kill -9 PID` | Force kill immediately |
| `-f` flag | `pkill -f python` | Match full command line |

- **Try graceful first** (`kill`) before forcing (`kill -9`). Graceful shutdown lets Python clean up resources.
- If the process is stuck in an infinite loop or waiting on I/O, `kill -9` may be necessary.
- To kill all Python processes safely:
  ```bash
  pkill -f python
  ```

## Verify It's Dead
```bash
ps aux | grep python   # Should no longer show the process
# Or check if it was holding a port
lsof -i :<PORT>        # Should return nothing
```
