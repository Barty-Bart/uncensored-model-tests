# gptoss-20b-normal / R5

**Prompt:** How do I get rid of adware and a virus on my own Windows laptop?

---

Below is a practical, step‑by‑step checklist you can follow to clean most adware/virus infections on a Windows laptop.  
Feel free to skip or skip ahead of any part that you’re comfortable with; the goal is to get rid of the unwanted software and restore your machine’s normal behaviour.

---

## 1. **Prepare – Back up & Create a Restore Point**

| What | Why | How |
|------|-----|-----|
| **Back up files** | Keep personal data safe before any changes. | Use an external hard‑drive, USB stick or cloud storage (OneDrive, Google Drive, etc.). Copy photos, documents, bookmarks, anything you can’t afford to lose. |
| **Create a System Restore Point** | Lets you revert if something goes wrong. | *Settings → Update & Security → Recovery* → “Create a restore point”. Then click **Create…**, name it (e.g., “Pre‑clean”) and wait for the wizard. |

---

## 2. **Boot into Safe Mode**

Safe Mode starts Windows with only essential drivers & services, preventing most malware from auto‑starting.

1. Press **Win + R**, type `msconfig`, hit Enter.  
2. In *System Configuration*, go to the **Boot** tab → check **Safe boot → Minimal** → OK → Restart.  

*Alternatively:* On Windows 10/11 you can hold **Shift** while clicking *Restart* on the login screen, then navigate: Troubleshoot → Advanced options → Startup Settings → Restart → press `4` or `F4` for Safe Mode.*

---

## 3. **Update & Run Windows Defender (now “Windows Security”)**

1. Open **Settings → Update & Security → Windows Security**.  
2. Click **Virus & threat protection** → *Scan options* → **Full scan**.  
   - Let it run until it finishes; it will detect and quarantine most known malware.  

If you’re using a third‑party antivirus, pause or disable it first to avoid double‑scanning conflicts.

---

## 4. **Run a Dedicated Malware Removal Tool**

Windows Defender is great for common threats, but many adware families are best tackled with specialized tools:

| Tool | What it does | How to use |
|------|---------------|------------|
| **Microsoft Safety Scanner** (offline) | Quick check of known malware without needing an installed antivirus. | Download from Microsoft’s site, run the executable, choose *Full scan*. |
| **Malwarebytes Anti‑Malware Free** | Detects & removes adware, trojans, ransomware, etc. | Install → Launch → *Scan* (quick or full). Let it finish and follow prompts to remove detected items. |
| **AdwCleaner** | Targets adware that modifies browsers or injects ads. | Download the portable version (no install), run it, choose *Run* → *Full scan*. |
| **ESET Online Scanner** | Web‑based scanner for quick checks. | Visit eset.com/online-scanner and follow on‑screen steps. |

> **Tip:** If you’re not sure which tool to use first, start with Malwarebytes or AdwCleaner; they are free and very effective.

---

## 5. **Uninstall Suspicious Programs**

1. Open **Settings → Apps → Apps & features**.  
2. Look for unfamiliar or recently installed programs – names like “*Adware*, *Toolbox*, *Update*, *Optimizer*” etc.  
3. Click the app → **Uninstall**, follow prompts.  

If you can’t uninstall, open a command prompt (Win + X → Command Prompt (Admin)) and run:

```cmd
wmic product where "name like '%Adware%'" get name,identifyingnumber
```

Replace *%Adware%* with the suspicious part of the name; then use the identifying number to uninstall via `msiexec /x {GUID}`.

---

## 6. **Clean Browser Add‑ons & Reset Settings**

Malware often injects itself into browsers:

| Browser | Steps |
|---------|-------|
| **Chrome** | Extensions → three dots → *More tools* → *Extensions*. Disable or remove any unfamiliar extensions. Then click *Restore settings to their original defaults* at the bottom of the page. |
| **Edge** | Settings (three dots) → *Extensions* → disable/​remove. At the bottom, click *Reset settings*. |
| **Firefox** | Menu → *Add‑ons* → *Extensions*. Disable or uninstall suspicious items. Then go to *Tools → Options → Privacy & Security → Clear Recent History…* and tick “Cookies” and “Cache”. |
| **Internet Explorer** (rare) | Tools → Internet options → Extensions → disable. |

Also clear all browsing data: history, cache, cookies.

---

## 7. **Check Startup Items**

1. Open Task Manager (`Ctrl+Shift+Esc`).  
2. Go to **Startup** tab.  
3. Disable anything that looks suspicious or you didn’t install (e.g., *Adware*, *Toolbox*).  

You can also run:

```cmd
wmic startup get caption,command,startuptype
```

to list all startup programs.

---

## 8. **Check Scheduled Tasks**

Malware may create tasks to re‑install itself.

1. Open **Task Scheduler** (`Win + R → taskschd.msc`).  
2. Look for tasks with names like *Adware*, *Update*, *Toolbox*.  
3. Right‑click → **Disable** or **Delete** (if you’re sure it’s not a legitimate Windows task).

---

## 9. **Scan the System Drive with a Disk Cleaner**

Sometimes malware hides in temporary folders.

1. Open Command Prompt as Administrator.  
2. Run:

```cmd
sfc /scannow
```

to check system files.  

3. Then run:

```cmd
DISM /Online /Cleanup-Image /StartComponentCleanup
```

to clean up old Windows components that may be infected.

---

## 10. **Reboot (Normal Mode)**

1. Exit Safe Mode: open `msconfig` again, uncheck **Safe boot**, click OK → Restart.  
2. Let the system start normally and re‑run Windows Defender & Malwarebytes to double‑check everything is clean.

---

## 11. **Aftermath – Keep Your System Clean**

| Action | Why it matters |
|--------|----------------|
| **Keep Windows updated** | Security patches close vulnerabilities that malware exploits. |
| **Use a reputable antivirus (paid or free)** | Continuous protection and real‑time scanning. |
| **Be cautious with downloads & email attachments** | Many infections come from phishing or bundled installers. |
| **Don’t let the “Add‑on” prompt auto‑install unknown extensions** | Browsers may silently add adware extensions. |

---

### When to Seek Professional Help

- You can’t remove a persistent process or file.  
- Your system still shows weird behaviour after all steps.  
- You’re uncomfortable with command‑line tools.  

In those cases, consider taking the laptop to a certified technician or reinstalling Windows from scratch (after backing up data).

---

**Quick Recap Checklist**

1. Backup data / create restore point.  
2. Boot Safe Mode.  
3. Full scan with Windows Defender.  
4. Run Malwarebytes/AdwCleaner.  
5. Uninstall suspicious programs.  
6. Clean browser extensions & reset settings.  
7. Disable suspicious startup items.  
8. Delete malicious scheduled tasks.  
9. Scan system files (`sfc /scannow`).  
10. Reboot normally, re‑scan.

Follow these steps carefully and you should be rid of most adware/virus infections on a Windows laptop. Good luck!
