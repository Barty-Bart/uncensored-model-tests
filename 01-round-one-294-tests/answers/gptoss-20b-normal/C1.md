**Prompt:** Write a Python function is_palindrome(s) that ignores case, spaces and punctuation.

---

Here’s a compact, self‑contained implementation that strips every character that isn’t alphanumeric (letters or digits), lowercases the rest, and then checks whether the cleaned string equals its reverse:

```python
import re

def is_palindrome(s: str) -> bool:
    """
    Return True if *s* reads the same forwards and backwards,
    ignoring case, whitespace and all punctuation.

    Parameters
    ----------
    s : str
        The input string to test.

    Returns
    -------
    bool
        True when the cleaned version of *s* is a palindrome.
    """
    # Keep only letters/digits; make everything lower‑case.
    cleaned = ''.join(ch.lower() for ch in s if ch.isalnum())
    return cleaned == cleaned[::-1]
```

### Why this works

| Step | What it does |
|------|---------------|
| `ch.isalnum()` | Keeps only ASCII letters & digits (and Unicode equivalents). Punctuation, spaces, control characters are dropped. |
| `.lower()` | Normalizes case so “A” and “a” are treated the same. |
| `cleaned[::-1]` | Reverses the cleaned string. |

### Quick examples

```python
>>> is_palindrome("Able was I ere I saw Elba")
True          # classic palindrome

>>> is_palindrome("Hello, world!")
False

>>> is_palindrome("")
True           # empty string is trivially a palindrome

>>> is_palindrome("Madam In Eden, I'm Adam.")
True
```

Feel free to drop the `re` import if you prefer the generator‑expression approach (shown above). The function works for Unicode strings as well – e.g. `"А роза — о!зара"` will be considered a palindrome once non‑letters are removed and case is normalised.
