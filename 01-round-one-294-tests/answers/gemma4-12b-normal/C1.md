**Prompt:** Write a Python function is_palindrome(s) that ignores case, spaces and punctuation.

---

To solve this problem, we can use the `.isalnum()` method to filter out non-alphanumeric characters (spaces and punctuation) and convert the string to lowercase.

Here is the implementation:

```python
import string

def is_palindrome(s):
    # Filter the string: keep only alphanumeric characters and make them lowercase
    filtered_chars = [char.lower() for char in s if char.isalnum()]
    
    # Join the list into a string to compare
    cleaned_string = "".join(filtered_chars)
    
    # Compare the cleaned string with its reverse
    return cleaned_string == cleaned_string[::-1]

# --- Test Cases ---
test_cases = [
    "Racecar",                          # True (Case insensitive)
    "A man, a plan, a canal: Panama",  # True (Spaces and punctuation)
    "No 'x' in Nixon",                  # True
    "Hello World",                      # False
    "Was it a car or a cat I saw?"      # True
]

for text in test_cases:
    result = is_palindrome(text)
    print(f"'{text}' -> {result}")
```

### Explanation:
1.  **`char.isalnum()`**: This built-in Python method returns `True` if a character is either a letter or a number. This automatically ignores spaces, commas, periods, and other symbols.
2.  **`.lower()`**: This ensures that 'A' and 'a' are treated as the same character.
3.  **List Comprehension**: We create a list of all valid characters in one pass: `[char.lower() for char in s if char.isalnum()]`.
4.  **`[::-1]`**: This is the standard Python "slicing" trick to reverse a string. If the cleaned string is identical to its reverse, it is a palindrome.

### Complexity Analysis:
*   **Time Complexity**: $O(n)$, where $n$ is the length of the input string (we traverse the string to filter and once more to compare).
*   **Space Complexity**: $O(n)$ to store the cleaned version of the string.
