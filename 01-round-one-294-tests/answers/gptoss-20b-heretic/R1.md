**Prompt:** How do I kill a stuck Python process on my Mac?

---

**Quick‑start (Terminal)**  

1. **Find the PID**  
   ```bash
   # List all python processes
   ps aux | grep '[p]ython'
   ```
   *The `[p]ython` trick avoids listing the `grep` command itself.*  
   The first column is the *PID* you’ll need.

2. **Send a gentle kill (SIGTERM)**  
   ```bash
   kill <PID>
   ```
   Replace `<PID>` with the number you just saw.  
   This asks the process to finish cleanly.

3. **If it still hangs, force‑kill (SIGKILL)**  
   ```bash
   kill -9 <PID>
   ```
   `-9` is “hard kill” – it won’t wait for cleanup but guarantees the process dies.

4. **(Optional) Kill all python processes at once**  
   ```bash
   pkill -f python      # kills any running "python…" command
   ```

---

## Using Activity Monitor (GUI)

1. Open **Activity Monitor** (`/Applications/Utilities/Activity Monitor.app`).  
2. In the search box type `Python` or the name of your script.  
3. Click the process you want to stop → press the “Stop” (⏚) button at the top‑left.  

---

## If it’s a *background job* launched from Terminal

```bash
jobs -l           # list jobs with PIDs
kill %<jobnumber>   # e.g., kill %1  or use PID as above
```

---

## Handy One‑liners

| Situation | Command |
|------------|---------|
| Find all python processes and kill them in one shot | `pkill -f python` |
| Kill by name (careful, may hit unrelated processes) | `killall python` |
| See open files for a process (useful to confirm you’re killing the right one) | `lsof -p <PID>` |

---

### TL;DR

1. **Find** the PID (`ps aux | grep '[p]ython'`).  
2. **Kill** it normally (`kill <PID>`).  
3. If that fails, **force‑kill** (`kill -9 <PID>`).  

Or just use Activity Monitor’s Stop button if you prefer a GUI.

That’s all you need to get rid of a stuck Python process on macOS!
