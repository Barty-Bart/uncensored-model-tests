## Quick‑Start Guide to Clean Your Windows Laptop  
*(Works for Windows 10/11; adapt the steps for older versions by replacing “Windows Settings” with your control panel)*

| Step | What you’ll do | Why it matters |
|------|-----------------|-----------------|
| 1️⃣ | **Back up your data** – copy your Documents, Pictures, Desktop files to an external drive or cloud. | If something goes wrong while cleaning, you have a safety net. |
| 2️⃣ | **Create a System Restore Point** | `Control Panel → System → System Protection → Create…` gives you a “before‑cleaning” snapshot that you can roll back to if anything breaks. |
| 3️⃣ | **Update Windows & Drivers** | `Settings → Update & Security → Check for updates`. Fresh OS files + drivers reduce attack surface and improve anti‑virus performance. |
| 4️⃣ | **Run a Full System Scan with Windows Defender** | `Windows Security → Virus & threat protection → Quick scan → Full scan` (or “Scan now”). This will catch most common malware. |
| 5️⃣ | **Add a dedicated anti‑malware tool** – e.g., *Malwarebytes Anti‑Malware Free* or *Kaspersky Virus Scanner* (free). Run a full system scan. These tools find things Windows Defender sometimes misses, like adware, rootkits, and “zero‑day” threats. |
| 6️⃣ | **Run an Ad‑ware cleaner** – e.g., *AdwCleaner*, *Spybot Search & Destroy*, or *CCleaner* (free). They scan the registry, startup folder, scheduled tasks, browser extensions, and delete known ad‑ware components. |
| 7️⃣ | **Check Browser Settings** | • In Chrome/Edge: `Settings → Privacy & Security → Clear browsing data` (cached images/files + cookies). <br>• Remove suspicious extensions (`chrome://extensions/`) or reset to default.<br>• Reset search engine and homepage if they’ve been changed. |
| 8️⃣ | **Clean Startup Entries** | Run `msconfig` (Windows 10: `Win+R → msconfig`) → “Startup” tab, disable anything that looks unfamiliar (especially those added recently). Or use *Autoruns* from Sysinternals to see all startup items and services. |
| 9️⃣ | **Delete suspicious scheduled tasks** | `Task Scheduler → Task Scheduler Library`. Look for tasks with names like *“Microsoft Windows Update”, “GoogleUpdate” or anything that looks odd; delete or disable them. |
|10️⃣ | **Run a Registry Cleaner** (optional) – e.g., *CCleaner* or *Wise Registry Cleaner*. Scan and fix bad keys left by old malware. |
|11️⃣ | **Reset Browser Profiles** | For Chrome: `Settings → Advanced → Reset settings to their default values`. For Edge: same under “Reset & clean”. This removes any hijacked homepage/search engine. |
|12️⃣ | **Check for Unknown Services** | Run `services.msc` and look for services that were added recently or have non‑Microsoft names; disable if you’re sure they’re malicious (e.g., *“AdwareService”*). |
|13️⃣ | **Use a “sandbox” to be extra safe** – e.g., *Sandboxie* or *VMware Workstation Player*. Run suspect programs inside the sandbox before installing them on your main system. |

## If the Problem Persists

1. **Boot into Safe Mode**  
   `Win+R → msconfig` → “Startup” → check “Safe boot” → restart. This runs Windows with minimal drivers and services, making it easier to remove stubborn malware.

2. **Use a Rescue Disk / Clean Install**  
   * Create a USB recovery drive (`Settings → Update & Security → Recovery → Get started → Create a recovery drive`).  
   * Boot from the USB, choose “Repair your computer” → “Troubleshoot” → “Advanced options” → “Command Prompt”.  
   * Run `chkdsk /f /r` to fix filesystem errors.  
   * If the malware is persistent (e.g., rootkits in the BIOS or boot sector), consider a full OS reinstall from a fresh ISO downloaded from Microsoft.

3. **Check for Rootkits**  
   * Use *Boot-Repair* or *Bootice* to examine your MBR/EFI partition and ensure no hidden code is running before Windows loads.  

4. **Consult Logs**  
   * `Event Viewer → Windows Logs → Security` – look for any suspicious logons, “System” → “Kernel‑mode driver loaded”, etc.  
   * Use *Process Monitor* (Sysinternals) to see which files are being accessed by unknown processes.

## Quick Checklist for Daily Hygiene

| Habit | What it does |
|-------|--------------|
| **Keep Windows & Apps Updated** | Reduces exploitable vulnerabilities. |
| **Use a reputable ad‑blocker** (uBlock Origin, AdGuard) in your browsers. |
| **Avoid “free” download sites** – use official Microsoft/Adobe/Google installers. |
| **Scan every new file or drive** with Windows Defender before opening. |
| **Back up regularly** – at least once a month (or more often if you’re very cautious). |
