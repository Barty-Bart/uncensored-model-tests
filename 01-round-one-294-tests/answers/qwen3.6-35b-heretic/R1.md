**Prompt:** How do I kill a stuck Python process on my Mac?

---

Here are several ways to kill a stuck Python process on your Mac, from easiest to most thorough:

## 1. Use `ps` and `kill` (Terminal)

**Find the process:**
```bash
ps aux | grep python
```

Look for your specific script/process in the output and note its **PID** (second column).

**Kill it gracefully first:**
```bash
kill <PID>
```

If that doesn't work, force kill:
```bash
kill -9 <PID>
```

## 2. Use `pkill` or `pgrep` (Quick & Easy)

Kill all Python processes:
```bash
pkill python
```

Or be more specific and target a particular script:
```bash
pkill -f "your_script_name.py"
```

## 3. Use Activity Monitor (GUI)

1. Open **Activity Monitor** (`Cmd + Space`, type "Activity Monitor")
2. Go to the **CPU** tab
3. Sort by **% CPU** or search for "Python" in the search bar
4. Select the stuck process
5. Click the **✕** button (or press `Cmd + W`)
6. Choose **Quit** (graceful) or **Force Quit**

## 4. One-Liner: Find and Kill by Name

```bash
kill $(pgrep -f "your_script_name.py")
```

Or kill all Python processes in one line:
```bash
pkill python
```

## Tips

- **`kill` (default)** sends `SIGTERM` — allows the process to clean up.
- **`kill -9`** sends `SIGKILL` — forceful, no cleanup guaranteed.
- Use `ps aux | grep python` to verify the process is gone after killing it.
- If you're running a Jupyter notebook or long-running script, consider using `Ctrl+C` in its terminal first before resorting to harder kills.

## Verify It's Dead

```bash
ps aux | grep python
```

If your process no longer appears (except for the `grep` itself), it's been successfully killed.
