### Ignoring Case, Spaces, and Punctuation in Palindrome Check
#### Function Description

The `is_palindrome` function checks if a given string is a palindrome, ignoring case, spaces, and punctuation.

#### Code
```python
import re

def is_palindrome(s: str) -> bool:
    """
    Checks if a string is a palindrome, ignoring case, spaces, and punctuation.
    
    Args:
        s (str): The input string to check.
    
    Returns:
        bool: True if the string is a palindrome, False otherwise.
    """

    # Remove non-alphanumeric characters and convert to lower case
    cleaned_s = re.sub(r'\W+', '', s).lower()
    
    # Compare the cleaned string with its reverse
    return cleaned_s == cleaned_s[::-1]

# Example usage:
if __name__ == "__main__":
    print(is_palindrome("A man, a plan, a canal: Panama"))  # True
    print(is_palindrome("Not a palindrome"))  # False
```

#### Explanation

1. The function uses Python's built-in `re` module for regular expressions to remove non-alphanumeric characters from the input string.
2. It converts the cleaned string to lower case to ignore case sensitivity.
3. The function then checks if the cleaned string is equal to its reverse (`cleaned_s[::-1]`). If they are equal, the original string is a palindrome, and the function returns `True`; otherwise, it returns `False`.
